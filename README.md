## Featured Project

### [The OI Ratio Edge — Expiry Day Index Options Intelligence System](https://github.com/ajayysainii/The-OI-Ratio-Edge)

> Zero-Indicator Derivative Analytics using Open Interest Ratio Imbalance, 1-Hour Price Action Retest & Power BI Executive Dashboard

| Dimension | Details |
|---|---|
| **The Problem** | 90%+ retail option buyers lose money due to lagging indicators and trading against institutional sellers |
| **My Approach** | 1-Hour consolidation zone identification (min 2 candles) + Sensibull OI Change ratio analysis |
| **Key Finding** | When OI ratio is 1:2+ (Strong Edge), win rate is **90%**. When ratio is ~1:1 (Weak), win rate drops to **28%**. Same trader, same SL — the OI ratio is the edge. |
| **Discipline** | 8 days skipped (no trade) when OI ratio showed no imbalance — protecting capital |
| **Results** | 57 trades, 82.5% overall win rate (90% on Strong Edge), ₹3.7L+ net profit, Profit Factor > 2.2 |
| **Excel** | 3-sheet workbook with live formulas — COUNTIFS, SUMIFS, AVERAGEIF, Profit Factor |
| **Power BI** | Executive dashboard — OI Ratio vs Win Rate attribution, Equity Curve, Index-wise breakdown |
| **Indicators Used** | **Zero.** Pure data + price action. |
