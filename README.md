## 🏆 Featured Project

### 📈 [Nifty & BankNifty Options Trading & Open Interest (OI) Analytics](https://github.com/ajayysainii/Options-Trading-Open-Interest-Analytics)

> Enterprise Derivative Trading Intelligence, Multi-Timeframe Price Action & Seller Open Interest (OI) Analytics using Advanced MS Excel & Power BI.

| Dimension | Details |
|---|---|
| **Market Problem** | 90% retail option buyers fail due to intraday noise & trading against institutional option sellers. |
| **Strategy & Logic** | 1-Hour Chart Key Levels (TradingView) + Sensibull Option Seller (OI) positioning for confluence. |
| **Excel Architecture** | Dynamic 3-sheet workbook with formulas (`COUNTIF`, `SUMIF`, `AVERAGEIF`, `IF`, `ROUND`). |
| **Power BI Dashboard** | Executive BI cockpit tracking Net PnL, Win-Rate %, Setup Attribution, and Cumulative Equity Curve. |
| **Key Metrics** | 60 Trades Sample • 50% Win Rate • ₹1,54,146 Net Realized Profit • 1:2.45 Average Risk-to-Reward. |
| **Tech Stack** | MS Excel • Power BI • DAX • Sensibull Derivative OI • Quantitative Risk Management |
